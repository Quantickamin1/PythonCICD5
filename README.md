# Документация проекта

## Общее описание решения

Проект представляет собой набор функций на Python для вычисления площади и периметра круга, прямоугольника, квадрата и треугольника.

## Описание функций с примерами вызова

### circle.py

#### `area(r)`

Принимает число `r` — радиус, возвращает площадь круга с заданным радиусом `r`.

**Пример вызова:**
```python
def area(r):
    '''Принимает число r - радиус, возвращает площадь круга с заданным радиусом r'''
    return math.pi * r * r
print(area(3))   # 28.274333882308138
```

#### `perimeter(r)`

Принимает число `r` — радиус, возвращает периметр (длину окружности) круга с заданным радиусом `r`.

**Пример вызова:**
```python
def perimeter(r):
    '''Принимает число r - радиус, возвращает периметр круга с заданным радиусом r'''
    return 2 * math.pi * r
print(perimeter(3))   # 18.84955592153876
```

### rectangle.py

#### `area(a, b)`

Принимает числа `a`, `b` — стороны, возвращает площадь прямоугольника с заданными сторонами.

**Пример вызова:**
```python
def area(a, b): 
    '''Принимает числа a, b - стороны, возвращает площадь прямоугольника с заданными сторонами'''
    return a * b 
print(area(4, 5))   # 20
```

#### `perimeter(a, b)`

Принимает числа `a`, `b` — стороны, возвращает периметр прямоугольника с заданными сторонами.

**Пример вызова:**
```python
def perimeter(a, b): 
    '''Принимает числа a, b - стороны, возвращает периметр прямоугольника с заданными сторонами'''
    return 2 * (a + b)
print(perimeter(4, 5))   # 18
```

### square.py

#### `area(a)`

Принимает число `a` — сторона квадрата, возвращает площадь квадрата.

**Пример вызова:**
```python
def area(a):
    '''Принимает число a - сторона квадрата, возвращает площадь квадрата'''
    return a * a
print(area(4))   # 16
```

#### `perimeter(a)`

Принимает число `a` — сторона квадрата, возвращает периметр квадрата.

**Пример вызова:**
```python
def perimeter(a):
    '''Принимает число a - сторона квадрата, возвращает периметр квадрата'''
    return 4 * a
print(perimeter(4))   # 16
```

---

### triangle.py

#### `area(a, h)`

Принимает числа `a`, `h` — сторона и высота, опущенная к этой стороне, возвращает площадь треугольника с заданными параметрами.

**Пример вызова:**
```python
def area(a, h): 
    '''Принимает числа a, h - сторона и высота, опущенная к этой стороне, возвращает площадь треугольника с заданными параметрами'''
    return a * h / 2 
print(area(6, 4))   # 12.0
```

#### `perimeter(a, b, c)`

Принимает числа `a`, `b`, `c` — стороны треугольника, возвращает периметр треугольника с заданными параметрами.

**Пример вызова:**
```python
def perimeter(a, b, c): 
    '''Принимает числа a, b, c - стороны треугольника, возвращает периметр треугольника с заданными параметрами'''
    return a + b + c 
print(perimeter(3, 4, 5))   # 12
```

# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = a * h / 2

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c
